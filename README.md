# 📊 Customer Churn Analysis & Data Pipeline

## 📌 Project Overview
This project delivers an end-to-end data analysis pipeline focused on predicting and understanding **Customer Churn**. By processing customer demographics, subscription details, and customer support interaction logs, the analysis identifies key drivers behind churn, evaluates revenue at risk, and outlines actionable customer retention strategies.

---

## 🛠️ Tech Stack & Tools Used
- **Programming Language:** Python 3.x
- **Data Analysis Libraries:** Pandas, NumPy
- **Data Visualization:** Seaborn, Matplotlib
- **Database Engine:** SQLite / SQL
- **Environment:** Jupyter Notebook / VS Code
- **Version Control:** Git & GitHub
